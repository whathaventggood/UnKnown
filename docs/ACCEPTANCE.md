# UnKnown 本轮交付与验收

验证日期：2026-11-17（Asia/Shanghai）。基于 `9ddefd8` 增量开发，保留 Vue/FastAPI/SQLite、原有三模式、种子与用户记录模型。没有公开部署、付费 LLM 调用或新的联网采集。

## 实际解决的问题

| 问题 | 实现与边界 |
| --- | --- |
| 原文证据缺失时把主题摘要归到来源 ID | 删除回退；原文与研究簇元数据分型；事实/不确定陈述要求逐字引用定位；位置成立不标为事实核验 |
| Cookie 修改请求缺少 Origin 时放行 | 私有 API 所有方法要求非简单头；Origin/Referer/Fetch Metadata、JSON、精确 CORS；代理显式 PUBLIC_ORIGIN |
| 300 条元数据可能被当作完整知识推荐 | 内容状态、来源指纹、中文准入、失败/恢复/费用限制；研究簇元数据不发布 |
| 只把浏览/标题重复当作未知程度 | 具体认知缺口、7/30/90 天覆盖、重复曝光、可关闭的双语词表与无历史探索 |
| 只有零散关系或把图当装饰 | 有界邻接检索、多步路径、逐跳来源、主动保存/继续/重开、依据变化降级 |
| 阅读后缺少理解检验 | 无 Key 自愿挑战、自由回答、隐藏参考、字词提示和自评；不自动判分或标理解 |
| 收藏与浏览不能表达回访意愿 | 独立一周后回访入口，可提前查看/取消，无签到惩罚 |
| 来源逐条查询与目录快照复制增长 | 批量加载、集合序列化、有限子图、共享不可变压缩快照、旧格式/旧策略重放 |

## 功能操作

1. 首页保留三模式和换组；“随机破壁”选择温和/跨界/完全陌生，可勾选不按个人历史；点击一次选择一条，页面不会自动连续抽取。
2. 详情增加更具体的认知状态、价值反馈和一周后回访。浏览、收藏、自述理解、作答和回访分别保存。
3. “图论 → 从这个知识继续探索”可沿既有资料走到社会网络、社会资本、公共物品。每跳显示事实/编辑教学联系、学科变化、解释与依据；没有可靠路径明确降级。
4. 点“保存这条路径”，在“我的探索 → 已保存路径”重开；继续或返回节点，保存的位置保留。只有主动保存的路径进入列表。
5. 详情“认知挑战”自由作答并保存，对照参考后自评；刷新能重新打开作答。引用材料变化时旧挑战返回 409，草稿保留。
6. “我的探索”查看 7/30/90 天覆盖、明确反馈、学习列表和自愿回访。没有反馈时相关比例显示不可计算；自测没有自动正确率。
7. 地图继续使用 ECharts，支持选择、局部展开、搜索、范围、节点层级、列表与移动入口；菱形表示自述理解，描边表示探索，金色描边表示收藏。
8. 清除当前档案删除路径/自测/回访等所有个人探索记录，保留共享来源、目录和非个人解释。

## 内容与来源实测

已有 60 个整理主题、12 主学科、22 条编辑关系保留。隔离数据库显式导入已归档的 OpenAlex 300 条后共 360 个主题；本轮逐条处理 300，全部 EXTRACTED，AI 调用 0，任务重跑不新增主题/不补造中文材料。缺失项含中文入门、核心问题/价值、仅研究簇元数据。

60 条种子通过本地准入，不表示专家审稿或逐句事实验证。来源许可、原始短摘与中文整理材料继续区分。OpenAlex 上游描述是机器生成的研究簇元数据，翻译也不能使其自动通过正文准入。Wikipedia/Wikidata 的既往在线超时未在本轮重新测试。

自动检查覆盖真实归档片段、来源无关的引用、合法 ID 上错置的片段、空白 quote、不确定陈述、教学类比、相互矛盾的受控输出和证据不足。结构检查只能拒绝错误归属/不在来源中的片段；“正确引用但陈述不被蕴含”仍标记未核验，未实现通用事实验证器或真实模型代表性人工审稿。
