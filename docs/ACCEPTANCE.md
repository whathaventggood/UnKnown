## 本轮功能优化（2026-11-17）

已实现：导航世代隔离详情/关联/聊天/收藏/反馈响应，解释深度与请求版本隔离，历史快照不会抹去新消息；关联和历史讨论独立加载、失败重试。模式在同标签页刷新后保留，详情返回恢复模式和滚动位置；换组失败复用幂等标识，曝光按原批次最多重试一次。

跳过显示后端有效期，可撤销且保留当前批次；明确其为后续推荐的弱减分，不承诺排除主题。新增“我的探索 → 学习列表”，按正在学习/自述已理解在服务端分页，支持回访及更新状态，收藏独立。列表按标题稳定排序，无迁移、无新增依赖、无伪造学习时间。

关系展示固定起点/终点名称及依据链接，读取旧批次时补齐桥梁中间节点名称，不回写快照。详情进入地图携带 root，地图选择该主题；无匹配时说明降级。卡片及学习列表保留数据中的摘要来源标签；未自动导入在线目录。

### 五分钟人工验收

1. 启动应用，选择“广域探索”，在页面下方打开主题再点“回到今日探索”：确认模式和位置保留；刷新确认仍是广域模式。
2. 卡片反馈点“暂时跳过”：看到有效期和说明；刷新后状态保留，点“撤销跳过”后消失。卡片集合不应自动替换。
3. 详情标记“正在学习”，去“我的探索 → 学习列表”：应可进入该主题；改为“自述已理解”，返回后在对应筛选找到它；移出列表后数量归零。另行收藏的状态应保留。
4. 打开“图论”及“社会网络”，核对两边的关系起终点方向相同、依据链接可打开；详情点地图应选中对应主题。访问 `/map?root=topic:missing` 应显示明确降级提示。
5. 在浏览器网络降速下快速切换模式、主题和解释深度，确认旧响应不覆盖新页面。把窗口改为 390px，重复学习列表和撤销跳过，检查无横向溢出。真实 AI 只在用户自行配置并明确触发时验证。

## 实际完成的用户路径

首次进入自动建立匿名档案，可填写或跳过熟悉领域、解释深度和探索强度。三种模式各自保存每天当前五条推荐；页面刷新稳定，换组创建带父批次的新批次，设置修改只提示不默默替换。

真实浏览器已完成：跳过初始设置 → 五条有出处推荐 → 原始摘要/来源详情 → 自述完全陌生 → 自述已理解 → 收藏 → 页面重载仍保留 → 我的探索时间线/收藏 → ECharts 真实节点渲染 → 地图列表搜索/键盘选择 → 查看真实探索和收藏状态 → 切换模式和换组 → 设置保存 → 取消清除保留记录 → 手机确认清除 → 新档案界面与统计归零。

“探索”定义为首次成功打开详情，并非理解。推荐生成、卡片可见曝光、访问、熟悉自述、学习状态和收藏分别持久化。不存在知识掌握百分比或学习成效承诺。

## 离线评估的解释边界

在相同候选库、历史前缀和五条预算下，每策略评估 15 批 / 75 个推荐槽位：兴趣基线平均覆盖 2.8 个主学科；分层随机与反信息茧房均为 5。反信息茧房在这组固定合成历史的近期重复为 0，另外两策略约 10.67%。所有原始试次、分母和熵归一化公式见 [EVALUATION.md](EVALUATION.md)。

这些仅证明本组输入上的算法行为，不代表真实用户陌生程度或学习收益。自述陌生比例没有真实反馈数据，显示 null。不能把分层随机基线同样达到五学科覆盖省略不报，或把约束通过率当正确率。

## 降级、已知限制与未实现范围

- 候选不足先扩大池，再按算法文档顺序放宽新机会/覆盖/单科上限/批量数量，响应保留实际数量和原因；不降低来源可追溯底线，不复制内容凑五条。
- 桥梁模式无可靠路径时显式降级；正式边保留类型、方向和来源。AI 类比不会自动进入正式图谱。
- AI 结构或来源 ID 有效不代表自动证实全部事实。尚未实现自动引用蕴含验证，也未完成真实模型的人工事实支持性抽查。
- 当前面向单机单 worker。AI 并发合并、聊天锁/清除世代与预算互斥不支持多实例；扩大部署前必须补持久化协调和相应测试。
- 图谱默认有限子图，最多150节点/300边/2层；候选与地图读取最多10,000主题。尚未进行大目录或并发压力/长时间稳定性测试。
- 普通来源缺少元数据、例子或教学问题时留空或使用有说明的代理默认值，不用模型补造。OpenAlex 目录的入门体验不等同于整理种子。
- 未实现账号、密码、同步、支付、社交、全网采集或本地大模型。这些属于本版明确非目标。
- 目前不提供金额估算、真实用户学习效果实验、真实反馈驱动的长期策略评估或自动跨设备档案恢复。
- 首次安装依赖仍需要网络或已准备的缓存；离线运行能力不等于无依赖安装。

此前额外启动验证曾因自动审批账户额度未完成而未执行；审批恢复后已重新执行并通过，不再作为当前阻碍。内置 CUA 浏览器控制连接超时，使用真实 Playwright Chromium 完成了浏览器验收；没有把构建成功当成浏览器通过。
