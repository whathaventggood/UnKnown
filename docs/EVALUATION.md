# 推荐离线评估

这是合成历史的算法行为测试，不是真实用户实验，也不证明学习效果提高。

共同候选库：60 个主题、12 个主学科；3 个固定合成历史，5 个固定种子 [11, 29, 47, 83, 101]，每个策略 15 批、每批 5 条。

| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |

## 口径与限制

- 四个策略（含冻结 v1 和新版）读取相同完整候选库、相同固定历史前缀和相同每批五条预算；多随机种子。历史不随策略扩展，没有未来行为。
- 全部策略共用：真实目录先通过中文内容和来源准入；隔离合成夹具明确标记 synthetic_test。可追溯 URL、质量代理≥0.4、可学习性代理≥0.25、排除已标记重复或异常。
- 每批实际主题涉及的唯一主学科数量；关联标签不计。
- 逐批 H=-Σp ln p，单位 nats；归一化版本除以 ln(当前共同候选库主学科总数)，不是除以批次大小。
- 实际推荐中，主题未探索且其主学科或细分主题未探索的比例。
- 实际推荐中，没有首次详情打开记录的主题比例。
- 实际推荐中，出现在人工指定的近期曝光前缀的主题比例；前缀为合成数据，不是实际用户事件。
- 每批五条、至少四主学科、每主学科≤2、至少两条新领域或细分主题机会、至少一条非热点内容全部满足的批次比例。
- 策略主动记录放宽约束的批次/总批次。两种基线无放宽流程，记为0；这不代表它们满足约束，需结合约束满足率。
- 质量和可学习性为实际推荐主题代理值的逐批均值，再对批次等权平均；不是事实正确率或学习成绩。
- 无真实反馈，自述陌生比例不可计算，JSON为null。合成画像不生成自述陌生标签。
- 无实际推荐的批次比例/均值分母排除；仍计入约束失败与降级率。固定种子和所有主题ID保留以复现。
- 仅评估算法行为，不证明提升知识掌握、认知能力或真实用户的陌生比例。

## 复现

```sh
python3 scripts/evaluate.py
```

完整逐批种子、历史指纹、主题ID和分母见 `docs/evaluation-results.json`。如种子库发生变化，需重新运行，不能把旧结果用于新候选库。

## 隔离性能实测

同一机器、本地 SQLite、每规模连续两批，未知模式、五条预算、初始空历史。60/360 为真实归档目录（其中合格候选均为 60），1000/10000 为隔离合成；模拟数据不进入正式库。

| 主题数 | 首批秒 旧→新 | SQL 旧→新 | 两批存储增量 旧→新 MiB | 地图毫秒 旧→新 |
| --- | --- | --- | --- | --- |
| 60 | 0.0340 → 0.0234 | 73 → 16 | 0.477 → 0.039 | 4.5 → 2.8 |
| 360 | 0.0828 → 0.0516 | 373 → 16 | 2.945 → 0.113 | 10.2 → 4.1 |
| 1000 | 0.3802 → 0.1828 | 1013 → 16 | 3.281 → 0.043 | 14.9 → 6.3 |
| 10000 | 4.0054 → 1.9146 | 10013 → 16 | 32.766 → 0.223 | 210.6 → 46.8 |

SQL 包括身份读取及一个额外发布数统计；新第二批少一条目录 INSERT。存储计入共享压缩目录及私人批次；合成字段重复度较高，压缩比不能外推真实万条文章。RSS 为进程累计高水位及其增量，不是每请求常驻内存；没有并发/长期稳定性结论。完整内存、查询、第二批耗时见 [旧基准](benchmark-baseline.json)、[新基准](benchmark-results.json)。

```bash
backend/.venv/bin/python scripts/evaluate_semantics.py
backend/.venv/bin/python scripts/benchmark.py --output docs/benchmark-results.json
backend/.venv/bin/python scripts/evaluate.py
```
