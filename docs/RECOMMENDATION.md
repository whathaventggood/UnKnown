# 可复现的未知知识推荐

策略 `unknown-rerank-2.0`，无网络、数据库或 LLM 依赖的纯排序代码。原有三模式、多样性、可行性 DP、约束与快照保留。旧版 v1 冻结用于历史重放。

## 实际推荐链路

1. Candidate Retrieval：从真实数据库批量读取最多 10000 条排序输入和来源；不临时生成条目。
2. Quality Gate：仅 PUBLISHED 内容，必须有合法来源，排除重复/异常，Q≥0.4、L≥0.25。数量不足不降低此底线。
3. Novelty Estimation：使用自述、首次探索、最近曝光、重复次数与长期覆盖；不点击不产生负反馈，浏览不等于理解。
4. Diversified Ranking：集合多样性逐次重算，使用分组小规模 DP 保持后续配额可行。
5. Constraint Validation：保留实际数量、达成值、放宽顺序和原因。
6. Explanation：真实特征模板生成理由，保存认知类型与权重证据。
7. Feedback Update：明确的认知状态、跳过、价值反馈、自评与回访独立保存；只有对应信号参与对应排序或统计。

## 新颖度与长期探索

认知类型包括：无接触记录、听过名称、了解概念想了解应用、想了解跨学科联系、主动标记忘记、明确陌生/了解，以及已探索但未证明理解。很久未访问只标记旧接触，不宣称用户已忘记。已了解的主题不计作新的未知机会；熟悉的整个学科不会被永久排除。

普通未知/桥梁权重仍是 `0.35N + 0.25Q + 0.20D + 0.20L`。N 增加 30 天主学科和细分领域的低覆盖奖励、明确的认知缺口、最近 30 天重复曝光抑制。7/30/90 天窗口保存首次探索分布；14 天实际曝光用于近期抑制，最多 200 个最近主题用于相似重复比较。窗口、截断范围和 as_of 随批次保存，不读取未来行为。

长期奖励为 `0.1 × (0.6/(1+近30天同主学科首次探索数) + 0.4/(1+近30天同细分领域首次探索数))`。最终 N 截断到 [0,1]；近期曝光、相似性、重复次数仍折减 N。它是陌生程度代理，不是心理测量。

D 继续采用不同主学科、细分领域及与已选主题相似度的边际贡献。L 使用入门材料、前置概念负担、已确认例子与真实桥梁；缺省值明示。短期跳过保留三天、0.12 弱减分和撤销，不永久屏蔽主题或学科。主动深入详情/路径不受每日跨科配额阻拦。

## 三模式与随机破壁

| 模式 | 实际策略 |
| --- | --- |
| 完全陌生 | 以 N/Q/D/L 重排，优先认知缺口与未探索细分领域 |
| 跨领域桥梁 | 优先真实、有类型与方向的连续路径，最多 3 跳；无路径显式扩池/降级 |
| 广域探索 | 固定种子打乱主学科分层次序；层内 N=.05、Q=.35、D=.40、L=.20，不按兴趣排序 |

广域 `broad_use_history=false` 时服务不读取个人历史用于排名，不应用跳过/曝光抑制，也不计算个人新机会；不保证避开已看过内容。

“随机破壁”一次仅主动抽取一条，复用相同发布与质量底线，策略权重确实变化：

| 强度 | N | Q | D | L |
| --- | ---: | ---: | ---: | ---: |
| 温和 | .15 | .35 | .10 | .40 |
| 跨界 | .40 | .25 | .10 | .25 |
| 完全陌生 | .60 | .20 | .10 | .10 |

优先未探索细分领域并抑制最近重复，没有热度加成。可选 `history_free=true`，相同候选、强度、种子在不同历史下结果相同；理由不声称知道用户是否了解。生成不等于曝光，卡片可见后才上报。幂等键绑定强度与历史选项，丢响应重试不多生成；每小时批次数上限保留。

## 可选中英相似度

`semantic.py` 是小型人工双语概念别名/共同机制词表，预计算到 `topics.semantic_features` 并按版本失效，不是通用嵌入模型。相同实体优先由已有 QID/外部稳定 ID 识别；语义相似只对排序作重复减分，不能合并两个独立实体。相同概念别名与共同机制的分值不同，后者不被直接当成近重复。

`SEMANTIC_SIMILARITY=false` 可关闭；未覆盖表达回退到英文词/中文双字 Jaccard。无需模型下载、远程调用或向量数据库。24 组人工探针比较见 [评估](EVALUATION.md)：有改善，也有误判/漏判，词表外泛化未经证明。未接入通用 embedding 服务。

## 约束、降级和长期可复现

每日五条仍目标至少四个主学科、每科最多两条、至少两条新领域/细分主题机会、至少一条非热点。先扩大真实候选池，随后按新机会→覆盖→单科上限等顺序放宽，候选不足少返回；不复制或编造主题。

批次按档案、IANA 时区日期、模式、批号持久化。设置变化不自动替换；换组使用父批次与幂等键。曝光、详情访问、首次探索、自述理解独立。来源更新导致条目退出 PUBLISHED 时，当前展示会停止该条并说明，历史排序输入仍保留以重放。

新目录快照保存完整排序输入，内容哈希寻址、zlib 压缩，不重复保存到每一批。私人历史、配置、随机种子、结果与理由仍随批次保存；源变化新建目录版本，旧版本不变。旧 JSON 原样兼容。

```bash
backend/.venv/bin/python scripts/replay_batch.py 批次ID
```

重放使用保存的策略版本/配置。算法离线评估仅描述固定合成输入上的行为，不能作为真实学习效果证据。主动改变模式、关闭历史、自愿回访、撤销跳过和清除档案均保留用户选择权。
