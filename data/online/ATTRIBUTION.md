# 在线元数据署名

来源：[OpenAlex / OurResearch](https://openalex.org/)。采集日：2026-11-17。保留300个去重研究主题元数据，适用 CC0 1.0；每条来源、外部ID、语言、更新时间和哈希都存于 [openalex.json](openalex.json)。本次采集与重导的实际数量见 [verification.json](verification.json)。

[OpenAlex Topics 文档](https://help.openalex.org/data/topics/) 说明研究簇的名称和 description 使用语言模型生成。这些英文标签/描述是上游原始元数据，不是本项目伪造条目，也不是专家审稿教学内容。默认产品仍使用可独立离线运行的60条编辑种子；导入本快照是显式操作。

分类是按查询批次选择的本项目入门主学科，外部 domain/field/subfield 独立保留，不宣称搜索词能够证明严格学科归属。未下载论文全文、图片或全量数据集。见 [许可](LICENSE)、[采集命令](../../docs/INGESTION.md)。
